# 指定学校顾问的建议文字编辑（v1.11.0 / schema5）

当前测评范围：本页报告操作沿用旧版14道规划/24道数字量表合同；新版游戏/30题特质尚未适配，明确拒绝进入旧云端或投影，不截断或混用分母。新旧档案与续答操作见 [测评版本说明](assessment-profiles.md)。

编辑必须由报告所有者**另行授权**。既有顾问只读、家长摘要链接和批注邀请不会自动获得编辑权，advisor角色不授予全校权限。本轮没有批量编辑、汇总导出、自动同步或生产部署。

## 所有者操作

主动连接并读取一份服务端报告，填写学校已创建的顾问账号，选择24小时、3天或7天。点击「预览编辑范围及文字基线」，核对完整报告范围、姓名/编号、题库与目录、源修订、接收账号及四段当前文字，再确认。系统不创建账号或发送消息，也不列全校账号。请自行通过学校允许的方式告知接收人入口。

这项授权允许接收人读取完整报告（姓名、逐题答卷、建议及便携修改历史），并在这一修订上**一次提交1–4段建议文字**：核心结论、学习行动、专业与职业、学习策略。不能修改作答、成绩、规则排序、身份、编号或版本。基线由所有者确认；已有顾问覆盖文字必须与库中一致，其余是当前同版本客户端规则生成的文案，不是服务端成绩或历史规则认证。

任何实际修改或其他设备更新都会使报告修订递增，原编辑授权和该修订的顾问只读授权关闭。需所有者读取新修订、复核并另授；单次提交可同时选多段，不是每段各可提交一次。仅首尾空白的无操作不增加修订或审计。到期/撤销/账号禁用/角色变化阻止后续操作，已经保存的文字不会因撤销恢复；已读副本不能收回。

可查看编辑授权历史、幂等撤销，并主动读取服务端编辑记录。每报告最多10份、每账号作为创建或接收共100份编辑授权历史，含撤销/过期/源变化，独立于只读额度；不静默清记录腾容量。删除原报告会删除这些授权及服务端编辑记录，界面有明确确认；本机归档不自动删除或替换。

## 顾问操作

打开学校同源HTTPS下的`advisor-edit.html`，主动连接、登录学校顾问账号、刷新有效编辑授权名单，再选择一份读取。打开页面、连接或登录不自动读取学生名单/答卷。只读入口`teacher.html`继续只读。

四段文字默认均未选中；修改所需段落并勾选，点击预览，核对前后文与源修订，再确认提交。每段1–4000 UTF-16码元，纯文本，不执行HTML；输入变化会使旧预览失效，提交不接受客户端author、actor、before或完整record。服务端只用实际登录ID取操作者账号，再验证权限与修订。

成功后旧详情和编辑权限清除，不自动读新修订；所有者另行读取新报告。冲突/撤权/失效不自动重试覆盖。提交响应丢失或临时网络故障时，原报告和基线清除，仅在内存保留本人改写草稿供复制，禁用再次提交；先复制留存，再主动核对授权/保存状态。刷新确认原授权已不再有效、原期限到达、换账号/断开/离开会清这些草稿。不能把响应未知当作未保存后重复提交。

页面不使用localStorage/sessionStorage、本机报告库或上传/分享/AI接口，没有自动轮询。题库/目录未知或与当前不符拒绝编辑视图；同版本仍是当前规则视图，原归档资料不被重算写回。撤销后主动刷新、失效读取、到期或身份变化会清旧报告与草稿，迟到响应不能恢复旧账号资料。多标签Cookie变化会由页面CSRF身份绑定拒绝。

## 修改记录的两种范围

每次实际提交在同一SQLite事务内更新所选建议、追加便携history并写服务端审计，CAS/容量/审计写入任一步失败都回滚。原state、成绩计算输入、reportMeta、版本、编号、创建时间保留；只更新建议、history、lastAuthor和记录更新时间。history最多200项，原每账号100报告/2,000,000序列化UTF-16码元容量仍适用，修订不能超过JS安全整数。

便携history作者标为「学校顾问」，可选actor记录完整登录账号（支持64字符）、用户/授权ID及源→结果修订，备份、导入、恢复和重新生成时保留。本机手工编辑不继承登录身份；不是AI来源，也不与AI origin混用。**便携记录可随所有者备份/重传改变，不能当作防篡改凭证。**

服务端审计单独只追加保存真实登录ID、当时账号、授权、源/结果修订、时间和逐段前后文。只有原所有者可通过专用接口读取，没有修改/删除审计接口；删除接收账号仍保留审计，删除原报告或所有者会级联删除。数据库操作员仍能改库，不是不可篡改日志、真实教师资质或人工审校证明。

## API

沿用健康API2、HttpOnly Cookie、精确Origin、写CSRF及浏览器认证读取的页面CSRF绑定。前后端一起更新，响应no-store/no-referrer/noindex。旧owner CRUD和只读接口不开放写权限。

| 方法 | 地址与范围 |
|---|---|
| POST | `/api/reports/{id}/advisor-edit-access`；所有者创建，体`{revision,recipient_username,ttl_hours,scope:"full_report_advice_edit",baseline:{summary,academic,plan,personality}}` |
| GET | `/api/reports/{id}/advisor-edit-access`；所有者授权历史 |
| DELETE | `/api/reports/{id}/advisor-edit-access/{grant_id}`；所有者撤销，204 |
| GET | `/api/advisor-edit-access`；指定顾问仅有效编辑授权 |
| GET | `/api/advisor-edit-access/{grant_id}`；指定顾问`{grant,report,baseline}` |
| PUT | `/api/advisor-edit-access/{grant_id}`；`{revision,changes:{所选段:文字}}`，返回`{report,changed_sections,audit_id}`；无操作时空列表/null |
| GET | `/api/reports/{id}/advisor-edits`；原所有者读取`{items}`服务端审计 |

元数据与只读同12键，仅scope不同；名单不读取答卷/基线。无权/失效404，有效授权提交不一致revision409，重复有效授权409 DUPLICATE，格式/额外字段422，容量413，损坏503不回显私文。审计列表与完整报告均是私密数据，不加入家长摘要/讨论或统计导出。

## schema5升级与回退

**任何初始化入口（包括API、开发入口或账号CLI）运行新版前，停止所有使用旧库的进程，在实际网站文档根目录外做完整一致私有备份并保留匹配旧源码。** 不要在线只复制主数据库文件就假定一致。新版仅接受精确已知schema1/2/3/4或当前5；在单事务中追加缺少结构后升5，新库直接5，未知/修改结构拒绝。

schema5新增advisor_edit_grants、advisor_edits和索引；原用户/哈希/会话/报告JSON/修订/分享令牌摘要/家长邀请与批注/teacher_grants全部逐行保留。失败回滚到原版本，不清库或重建用户。旧只读授权不会变成编辑授权。

旧程序不能直接读5。回退需先停新版、保留新库，再恢复与旧代码匹配的升级前私有备份，评估备份后新报告/授权/审计损失；不能手改user_version或覆盖唯一新库。迁移验证不等于正式部署，当前仍为单进程，正式HTTPS/反代/ACL/私有备份/可信代理/容量需公司环境验证。
