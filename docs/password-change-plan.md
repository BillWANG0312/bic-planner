# 本人改密与全部会话撤销方案（2026-10-25）

沿用用户自主推进授权，本阶段只做本人改密，不做找回、注册、邮箱/短信或管理员重置。schema5/API2保持，不新建表。原报告/授权/分享/批注/审计与其他账号会话不改变。

## 后端合同

新增`POST /api/auth/password`，严格body只有`current_password`与`new_password`字符串，各12–128 Unicode码点、有效UTF-8；新密码与创建账号一致且不能全空白或与旧密码相同。确认新密码由前端核对，不把重复口令再次传API。保持同源/CSRF、当前会话/启用校验、共享账号/IP尝试上限与Argon2并发资源上限。错误体不回显输入，成功204清当前Cookie，不生成新会话。

`AuthService.change_password(rawtoken, csrf_token, current_password, new_password, ip)`：重读当前会话和账号，计入与登录共享的尝试上限；验证旧Argon2后生成新哈希。数据库单事务同时检查当前token哈希/CSRF/期限、账号启用与被验证的原password_hash，CAS替换并删除该user全部session。已注销/到期/被禁用或并发另一更改均不能提交；会话/凭据失效401，旧密码错误401，新密码不合法/相同422，哈希繁忙/尝试超限429，存储失败503。删除或更新任一步失败整体回滚，不回显密码/哈希。服务不写凭据日志。

登录验证旧哈希与会话创建间存在竞态，需使`create_session`支持事务内检查expected_password_hash，`AuthService.login`传被验证哈希；不阻断既有内部调用的兼容行为。改密先提交则旧哈希登录失败，登录先提交则新会话也被改密一并撤销。仅撤会话不撤报告授权/令牌，不声称已经复制的资料或正在处理中的其他请求能收回。

## 客户端与界面

`CloudReports.changePassword(currentPassword,newPassword)`为显式已认证单次请求。先校验且不清本人身份；发送前取消本client既有待请求，保留本次user/CSRF/generation绑定。调用后本页断开并忘身份，成功只接受204，不自动重试或登录；网络/超时/异常成功结构等结果未知也清本页会话，要求主动重新登录核对。迟到响应不得清后来重新建立的身份；离开/断开/取消时拒绝迟到成功。增加适当非成功/未知状态文字，不把未知写成失败未改。

12–128口径与Python创建/登录一致，JS按Unicode码点且拒绝孤立代理项。既有login口令校验同步修正，HTML/动态密码输入maxlength扩至256 UTF-16以容纳128非BMP字符；仍由JS/后端验证码点数量。只调整密码输入，不扩其他文本/存储限制。

新增独立`account.html`/`js/account.js`/`css/account.css`，仅加载config/client/account模块，不加载题库/报告/本机库，不访问存储，默认不联网。明确连接、登录或恢复本人会话后展示账号及改密表单；当前密码/新密码/再次输入新密码。submit先捕获当前身份并校验两次新密码，一次明确确认“改密且所有设备需重登”；确认取消清三输入不请求。确认前后账号/输入/本地到期必须一致，忙时禁止重复提交，程序变化不能发出旧密码。

发送前清三输入，成功清账号并提示全部会话已撤销、主动重登；未知结果不假报成功，清私密/断开并说明先尝试新密码，若未成功再主动尝试旧密码，不自动轮试。离开/断开/退出/取消/到期清密码输入；离开后的晚结果不能恢复状态或断开新账号。4000字私文等不应进入页；375px可用。主站提供普通导航到账号安全，不改变其他入口的账号/权限用途。
