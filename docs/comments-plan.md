# 受控家长批注阶段

本段在当前未合并草稿 PR #6 上顺序实现账号授权与私有批注，不改生产。普通只读分享令牌继续只读，不新增匿名写入口。

采用既有学校账号与单报告邀请，不新增有全局权限的家长角色或公开注册。报告所有者输入已存在且启用的接收账号，预览并确认固定摘要、源修订及24小时/3天/7天期限。授权快照独立于匿名分享，有独立期限和撤销；转发只读链接不能取得批注权。

每份邀请为所有者与该接收账号的单独线程；其它家长不能互看。批注仅追加、1000 UTF-16码元/条、每线程100条，不改变成绩、建议或顾问审计。写操作必须登录、精确Origin、会话CSRF，并用UUID请求号避免断线后重复提交。撤销/过期/任一账号禁用后接收人不可读写；所有者可读历史但不能继续写。报告删除会删除相关邀请及批注，界面明确告知。

为保留审计，邀请不随失效自动清理；本段上限含历史每报告10份/每账号创建或接收共100份，扩容或归档需明确后续设计，不能静默丢记录。独立family.html主动连接登录后查看自己的授权，旧会话/线程响应不能影响新账号或草稿。

数据库精确识别已知v1/v2并单事务升v3，用户表/角色不变，保留原密码哈希、会话、报告及匿名分享。失败回滚、未知仍拒绝。升级前私有备份，旧程序不能直接读新库。先权限/模型/TDD，再真实浏览器与独立审查及完整回归。
