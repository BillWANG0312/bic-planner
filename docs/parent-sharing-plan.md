# 家长只读分享阶段

继续当前未合并草稿 PR #6，顺序交付已独立验证的阶段，不改公司生产环境。本段只做 owner 明确确认的只读摘要、期限、撤销与权限；批注随后单独实现。

摘要包含姓名/年级/目标年份、原报告编号日期、版本与修订、四科完成状态/完整科目百分数、探索方向/性格提示与四段最终建议。客户端按已读取服务端归档生成，服务端严格限定公开字段并绑定所拥有报告的 revision；没有原始答卷、题干解析、账号名单或顾问审计。不把所有者生成的规则摘要说成正式成绩或录取概率。

分享为固定快照，更新报告不改变旧快照；删除报告、禁用所有者、到期或撤销后不可读取。令牌用安全随机生成，只在创建返回一次，数据库只存摘要。链接令牌放 share.html 的 fragment，读取请求通过自定义头传递，URL 路径/查询不含令牌。独立公开页不加载测评应用或访问浏览器存储，手动读取、不发送Cookie、不含写能力。

数据库精确识别已知 v1 后事务迁移到 v2，保留原账号/报告/会话，失败回滚，未知结构仍拒绝。单报告最多 5 活跃分享、账号最多 100；下次创建可清理同账号已失效分享元数据。先测试模型和迁移，再真实浏览器联调、独立审查与完整回归。

技术依据：[MDN Fragment](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment) 说明片段不随资源请求发送；参考 [OWASP 令牌存储与到期原则](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)，借用随机、安全存储、期限等原则，分享令牌在有效期内可重复读取，并非密码重置令牌；[sqlite3 事务文档](https://docs.python.org/3.12/library/sqlite3.html) 用于迁移失败保护。正式反代不得记录敏感请求头，HTTPS/私有备份与容量验证仍是部署依赖。
