# 可选专业分布与地区偏好（v1.8.0）

当前测评范围：本页报告操作沿用旧版14道规划/24道数字量表合同；新版游戏/30题特质尚未适配，明确拒绝进入旧云端或投影，不截断或混用分母。新旧档案与续答操作见 [测评版本说明](assessment-profiles.md)。

在原 [本地学术汇总](academic-statistics.md) 中增加默认不勾选的专业/地区扩展。仍需主动选择10–100份本机报告、声明来源、核对每位学生至多一份，预览后再次确认导出。没有联网、统计持久化或成绩/难度阈值更改，真实样本校准仍未完成。

## 选择范围与版本

默认仍输出纯学术JSON，`format: bic-academic-aggregate, version: 1`，原科目、逐题、缺答和小单元规则不变。只有明确勾选「包含专业与地区分布」才输出`version: 2`并新增`planning`；v2的原学术部分与同批v1相同，不能把扩展默认为自动收集。

扩展要求所选归档同时使用当前题库和院校目录版本。已选旧目录报告不会被静默取消；页面提示并停止生成，需操作者明确取消这些报告，或取消扩展继续纯学术v1。v1仍允许不同院校目录。目录一致只是本轮保守的混算限制，**不能证明历史规划规则相同**；归档没有独立规则快照，扩展明确标记按当前本地规则重算，不复原归档当时的推荐。

切换扩展选项与更改报告/来源一样会清旧预览。导出前和确认框后复查模式及所选归档的完整内存快照，内容或范围变化会停止导出；不会静默换成另一批或另一种格式。确认框注明纯学术v1或学术+专业/地区v2。JSON不是原始备份，不能恢复学生作答。

## 三张表的口径

| 表 | 来源与纳入条件 | 分母及排除含义 |
|---|---|---|
| 当前规则推荐专业 | 用实际报告引擎重算；仅完整学术、规划与人格测评的报告，每份取第一推荐方向一次 | 纳入的完整报告数；排除指测评未完整，不是没有专业意向 |
| 学生明确专业意向 | 直接读取该题已选固定选项；即使整份规划未完成，已回答此题仍纳入 | 回答专业意向题的报告数；空数组/未填为缺答，不算不确定 |
| 学生明确地区偏好 | 直接读取地区题已选固定选项，使用学生选择，不使用系统推荐地区 | 回答地区题的报告数；未填为缺答 |

规则推荐使用14个专业ID，如`cs/biz/psych`；学生明确意向使用题目的12个原选项，如`tech/business/social`，不能互相替代。自然科学等较宽的意向不会被冒充精确课程选择。地区使用8个原选项，如`uk/us/ca/.../unsure`，不输出自由地区或自行推断的目的地。

两张明确偏好表均允许多选。一份报告对同一选项最多计一次，分母是回答该题的报告数，**不是所有选择次数**。所以选择次数可大于报告数，各项百分比之和可超过100%。`unsure`是有效作答，可以与具体选项同时出现；不会被强行改成缺答、互斥选项或确定选择。零作答时比例为空，不生成默认推荐或0%意愿判断。

规则推荐描述的是当前规则排序，不是学生亲自选择、录取概率或已认证的最终专业；不能拿部分作答时规则强制产生的第一名冒充完整结果。三表不交叉分组，没有专业×地区、年级、学校或人格分布。

## 整表隐藏与输出

沿用内部最小正单元10的策略，对每表独立检查：纳入数、排除数、每项选择数及「纳入数减该项选择数」。任一正值小于10即隐藏**整张表**，不输出该表的纳入/排除/选择次数、条目、百分比或逐项隐藏状态。这样不会仅隐藏一个罕见选项，却通过总数或未选择者补集直接反推。零允许，未作答整批可显示0纳入/全部缺答、比例为空。

这个门槛不是匿名认证、法律标准或代表性证明。多个边际表、原学术均值、已知背景与反复子集仍可能识别个体；导出仍只供校内复核，不可据此称为充分匿名或任意公开资料。来源与每人一份只由操作者核对，系统不认证真实学生或使用授权。

v2新增的结构为：

```text
planning:
  ruleBasis: current_local_rules_recomputed
  catalogVersion: 当前目录版本
  recommendedMajors: 当前规则推荐表
  statedMajorPreferences: 明确专业意向表
  regionPreferences: 明确地区偏好表
```

每表都有`status/basis/selectionMode/denominator`，分母标识固定`included_reports`。只有`status: available`时才有`included/excluded/selectionCount/entries`，每条仅固定枚举`key/count/pctOfIncluded`。固定枚举标签取自本机配置，JSON不含姓名、学号、报告/归档编号、原始答案、自由学科文字、精确日期、顾问记录或人格画像。

原`calibration.status: not_calibrated`、`followupOutcomes: false`、`thresholdsChanged: false`保持。没有真实后续成绩，不能把这些描述分布称为样本校准、招生预测或A/B完成率/分享率比较。另有独立 [后续成绩人工配对工具](outcome-review.md)，只用虚构资料完成工具验证，不把后续文件自动混入本v1/v2汇总，也未完成真实样本校准。

开发使用虚构资料，回归覆盖默认v1、显式v2、目录与完整度、缺答/unsure/多选分母、罕见计数及补集整表隐藏、模式切换和快照新鲜性、真实宿主导出与375px显示。最终验证结果与交付记录见 [持续台账](progress.md)。
