# 家长只读摘要分享（v1.4.0）

当前测评范围：本页报告操作沿用旧版14道规划/24道数字量表合同；新版游戏/30题特质尚未适配，明确拒绝进入旧云端或投影，不截断或混用分母。新旧档案与续答操作见 [测评版本说明](assessment-profiles.md)。

在已开通的账号服务中，报告所有者可以分享一份固定摘要。默认静态配置仍关闭，不自动上传或发送链接，也没有匿名写入或批注入口。本阶段仅完成代码与本地验证，没有改公司生产环境。

## 创建、读取和撤销

1. 主动连接并登录账号，读取需要分享的服务端报告详情，点击「预览分享摘要」。摘要取自已读取的服务端归档，不使用另一个当前学生。题库/目录版本过旧时须先复核并更新服务端记录。
2. 核对姓名、科目完成情况、方向、性格提示和四段最终建议，选择 24 小时、3 天或 7 天有效期，确认生成。若源报告修订已变化则停止，要求重读；不会自动改用新修订号。
3. 链接只在创建成功时显示一次，可以手动复制，系统没有发送给任何人。离开、切换报告、退出或会话失效会清除页面中的链接，不写浏览器存储或备份。
4. 家长打开独立 share.html，明确点击「读取分享报告」。页面没有账号、作答、编辑或本机导入功能，不访问浏览器测评存储、不发送 Cookie。链接片段立即从地址栏隐藏，刷新需重新打开原链接。
5. 所有者点击「查看已有分享」读取期限与修订，可撤销任一有效分享。已有链接的令牌不会再次显示。撤销、到期、删除原报告或禁用所有者账号后，新的读取立即失败；错误不区分具体原因。

任何持链接者都可读取，接收者也能转发链接。请自行只交给预期接收人；撤销不能收回已经读取、下载或截图的内容。公开页不会自动轮询撤销状态，每次明确读取均重新检查；到期会清理本页摘要。报告更新不会修改旧快照，要分享新内容需另行生成，建议同时撤销旧链接。

## 分享了哪些资料

固定白名单包含姓名、年级、目标年份、原报告编号/日期、题库及院校目录版本、源修订、四科学术测评完成数及完成后百分数、专业方向、性格提示和四段最终建议。未完成科目不显示百分数。

不包含逐题答案、题干/解析、账号列表、密码/会话、顾问作者与完整修改审计，也不接受任意 HTML。摘要文字用 textContent 显示，形如 HTML 的文本不会执行。摘要由所有者的浏览器按当前规则生成，服务端严格校验公开字段并绑定所属报告的修订，没有另行完成服务器评分或第三方人工认证；它不是正式成绩或录取概率。

每份报告最多 5 个活跃分享，每账号最多 100 个。下次创建会在事务中清理该账号已过期/撤销的分享元数据，不改活跃分享或原报告；失效的原链接仍不可用。

## 接口与部署

账号接口沿用 API v2 会话绑定，所有写操作需正确 Origin 与 CSRF，认证读取也带内存 CSRF。

| 接口 | 行为 |
|---|---|
| `POST /api/reports/{id}/shares` | `{revision,ttl_hours:24或72或168,content}`，校验所有权/修订；201 返回元数据及仅此一次的随机 token |
| `GET /api/reports/{id}/shares` | 自己报告的分享元数据，没有 token 或公开摘要全文 |
| `DELETE /api/reports/{id}/shares/{share_id}` | 撤销自己的分享，204，不修改报告 |
| `GET /api/public/share` | 仅凭 `X-BIC-Share` 令牌读取严格摘要，无登录 Cookie、无账号操作能力 |

令牌用安全随机生成，数据库只存 SHA-256 摘要。链接采用 `share.html#share=...`，令牌不放请求路径/查询，通过指定请求头提交。公开响应 no-store/no-referrer/noindex；页面有严格同源 CSP，拒绝跨域、重定向、超大响应和不受支持的结构。匿名读取默认单进程每 IP 每分钟 60 次，反代下共享来源 IP，正式容量/可信代理方案仍待公司验证。

静态托管需同时包含 share.html、css/share.css 与 js/share-{summary,view}.js。沿 [连接指南](cloud-connection.md) 配置同源 API 和 Cookie 路径；正式使用 HTTPS。代理不得记录 `X-BIC-Share`、Cookie、CSRF 或请求/响应正文。建议 share.html 响应另加 `Content-Security-Policy: frame-ancestors 'none'` 与 `X-Frame-Options: DENY`（frame-ancestors 不能靠 HTML meta 生效）；保留其余同源 CSP。不要添加第三方分析脚本。

## 数据库升级

升级运行前，正常停止服务并将原 SQLite 完整备份到站点外的私有目录。新程序只对 application_id 与原表/索引 SQL 均精确匹配的已知 schema v1，在同一写事务内创建分享表/索引并升级到 v2；账号哈希、报告 JSON、修订和会话不改动。中途失败回滚到 v1，未知或篡改结构拒绝，不重建清库。

旧程序不能直接读取 v2。若回退，先停新程序、保留新库，再从升级前备份恢复与旧程序匹配的 v1；回退会失去升级后的新增记录，必须由维护者评估并另行保留，不要用旧程序覆盖新库。这不是线上部署或恢复演练已完成的声明。

本地同源入口 `python -m backend.bic_api.dev` 已包含公开页；`pnpm run test:cloud` 覆盖实际 Chromium→FastAPI/SQLite 的创建、匿名读取、固定快照、撤销及旧修订拒绝。迁移失败保护、期限边界、禁用/删除与跨所有者权限另由 Python 用临时虚构数据验证。后续已增加 [学校账号批注与 v3 升级](family-comments.md)，其邀请和匿名分享是独立权限；教师跨用户分配、改密找回仍待推进。
