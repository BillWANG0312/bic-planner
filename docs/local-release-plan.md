## 本次验收

- 修复错误答案、学科专业匹配、MBTI 方向、超过 100% 的匹配展示和年级时间线。

- 60 道原创学术题（每科 15 题），基础 / 中等 / 进阶标签、题库版本。原 30 题的 ID 和顺序不变。新增题目标记待教师审校。
- 院校数据独立维护，保留历史参考状态与可核实的官网链接。没有复核证据的录取要求不得标成最新要求。
- 未完成测试生成草稿，展示完成度，不把未答解释为确定的能力或人格结论。

- 顾问修改、版本与历史随本地报告保存；更新测试后保留修改，并在报告正文及 PDF 中提示复核；重新测试清空数据需确认。
- 打印时展开逐题解析，打印后恢复浏览状态。移动端操作不溢出。

## 实现与验证

保留现有脚本结构：题库/数据、报告引擎、应用交互分别并行修复；新增独立的报告编辑模块，由应用保存回调持久化，渲染层显示编辑后的文字。使用 Node 原生测试覆盖真实报告引擎，用 Playwright 覆盖真实浏览器交互与打印事件。各功能先运行失败回归用例，再实现和重跑完整测试。最后独立代码审查并输出可部署静态包、Git 补丁与中文交付说明。

## 边界

本地模式只保存当前浏览器中的一个学生报告，不冒充教师多学生后台、云端备份或跨设备分享。院校匹配不提供录取概率或保底保证。新增题目及历史院校要求仍需公司教师审校。本次代码通过分支交付，不合并或部署生产网站。
