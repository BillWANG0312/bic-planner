## 边界

初版保留一个当前学生进度；后续本地阶段已增加明确的本机多报告库、JSON 手动备份/导入和 CSV 汇总，详见 report-library.md。本机库按浏览器/网址存储；另有默认关闭的账号服务、主动上传、只读分享与受控批注，均已完成本地验证，详见连接指南。可选文案草稿已完成本地模拟、回退与人工确认，没有真实模型接入。本地汇总需显式选择、来源核对与预览确认；默认纯学术v1，可明确勾选专业/地区v2，区分完整报告的规则推荐与学生多选偏好，整表保护稀有计数及补集。只作描述复核和校准准备，不联网或改阈值，不能称充分匿名。教师跨用户后台和自动同步尚未实现。院校匹配不提供录取概率或保底保证；题库教师审校和真实样本校准仍待完成。本次代码通过分支交付，不合并或部署生产网站。
