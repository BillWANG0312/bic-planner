# 本地学术汇总与校准准备（v1.7.0）

本轮提供四科学术描述汇总和逐题复核。统计由用户从本机报告库明确选择后在浏览器计算，不访问账号服务，不上传答卷，不新增统计存储。**输出是去标识汇总，仅供校内复核；不能据此称为充分匿名、可公开数据或已完成真实样本校准。**

## 使用

1. 在「本机报告库」点击「学术汇总与校准准备」。进入报告库本身不会选择或生成统计。
2. 逐份勾选10–100份报告，并明确选择「模拟/演示样本」或「真实来源待核验」。统计单位是报告，不是已认证的独立学生；核对每位学生至多一份后勾选确认。系统只检查归档/报告编号重复，不通过同名判断是否同一人。
3. 只选择与当前题库相同版本的归档。旧题库项不能混算，不会默默改用新答案。纯学术汇总不要求院校目录相同；重新生成旧报告不能代替当年题目与作答一致性的人工核验。
4. 点击生成预览，查看四科完整/未完整份数、完整科目的粗粒度均分及逐题已答/缺答/正确情况。缺答单列，不能解释为答错或能力不足。部分完成科目不进入科目均分。
5. 核对完整JSON预览后点击导出，确认来源、份数和识别风险，才下载同一份JSON。取消不下载。此文件不含答卷，不能导入恢复学生报告。

更改选择、来源或核对勾选会使旧预览失效。导出前重新读取所选归档，与生成预览时的内存快照比较；内容变化、删除、损坏或存储读取失败均停止导出，需重新选择核对，不自动替换预览。关闭或离开报告库会清选择、姓名列表与预览；导入/删除造成库刷新也会清理。

来源选择只是操作者声明，不是对真实样本、使用授权或代表性的认证。当前开发与演示均使用虚构资料，没有读取真实学生样本或后续成绩。完整原始备份与普通CSV仍包含学生资料，请按原有 [本机报告库说明](report-library.md) 分别保管。

## 计算口径

- 严格校验所选归档的类型、题目、选项、数量和重复编号，再复用报告现有评分和逐题回顾重算，不信任缓存成绩或顾问文字。
- 四科每科15题。完整科目的均分从正确题数计算，四舍五入到最近5个百分点，仅作粗略样本描述；不是A-Level成绩预测或能力等级常模。
- 逐题正确比例为「正确 / 已答」，不把缺答放进答错分母。零作答的比例为空，不显示0%成绩。
- 完整与未完整两个份数中，任一正数小于10，则整个科目行压制，不输出计数或均分。逐题正确、错误、缺答三格中任一正数小于10，则整题压制，不输出其计数、分母或比例。零格允许；不单独显示罕见格的补集。
- 10为本产品的内部发布门槛，不是法律标准、匿名证明或统计可靠性门槛。均值、不同题目之间的组合以及多次选择近似子集仍可能被反推；不得将导出作为可任意公开的匿名资料。
- 逐题「无人作答 / 全部答对 / 全部答错 / 描述复核」只帮助定位需要学科教师查看的项目，不自动更改题目难度、答案或等级阈值。选择偏差、一人多次测评、年级差异与样本量均可能影响结果。

输出仅白名单字段：当前题库版本、来源声明、报告份数、固定隐私说明、科目汇总、当前题目ID/科目/编辑难度及允许显示的汇总，以及未校准状态。没有姓名、学号、归档或报告编号、精确日期、年级、地区、人格、原始答案、顾问文字或修改历史。界面选择列表中的姓名只在本机用于辨认，不写入统计JSON。

## 校准边界与后续

JSON固定标记 `calibration.status: not_calibrated`、`followupOutcomes: false`、`thresholdsChanged: false`。本工具不能从本次答题正确率单独得出真实后续成绩或校准能力等级阈值，没有进行模型训练、常模建立或真实结果验证。

下一小段单独处理专业分布与地区偏好的整表压制规则，再推进真实后续成绩的本地配对与校准验证工具。真实样本来源、适用授权、独立性、时间范围及学科教师审校需要公司确认；缺这些资料时只测试工具行为。规则/AI报告的A/B完成率和分享率还没有收集事件，不能虚构比较结果。

运行无需后端、Node或密钥，file://继续可用。开发测试先失败后实现，覆盖小样本/补集压制、缺答与数值题容差、版本与重复、来源、快照变化、取消下载、纯文本和375px显示；完整结果及准确后续见 [持续台账](progress.md)。
