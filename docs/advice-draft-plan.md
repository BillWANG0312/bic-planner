# 可选文案草稿阶段

本段继续当前未合并草稿 PR #6，只做可替换接口、本地确定性模拟、规则回退与人工确认，不创建密钥、不选择/开通厂商、不调用付费模型、不发送真实学生资料。默认关闭，正式适配器与服务批准仍是后续依赖。

生成与应用分两步：所有者明确发起，数值/枚举上下文不含姓名、报告编号、原始答案或自由文案；当前四段规则/顾问文字仅留在本校服务内部作回退。供应商接口只接收严格的数值上下文。本地模拟须明确标识，不伪装成真实AI；失败、超时、无适配器或关闭均返回原文字，不自动写报告。

草稿私有内存保存15分钟，容量有界，重启后失效。最多两个有界daemon任务，超时不无限开线程；真实适配器仍必须自带可靠超时与公司数据处理规范。应用需预览、选择建议部分、填写审核者并确认；服务端只取已保存草稿，验证所有权、源修订及TTL，只改四段建议并保留带来源的修改历史，状态/成绩/原编号不变。应用只更新服务端，不自动覆盖本机学生。

origin为私有修改历史的可选字段，包含规则/本地模拟/模型来源、生成器、草稿ID和源修订。旧备份兼容，手工编辑/恢复新历史不冒用生成来源，公开家长摘要继续不含审计。数据库schema保持3，不新增表。先TDD，再真实回环浏览器/独立审查与完整回归，不宣称语义核验或真人审校完成。
