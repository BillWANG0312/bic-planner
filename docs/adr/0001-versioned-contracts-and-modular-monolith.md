# 保留离线前端与模块化单体，以版本合同隔离报告操作

采用现有纯静态离线前端和可选FastAPI/SQLite后端，将不可变测评profile、严格归档合同与按操作声明的兼容能力集中管理。当前重复故障来自两代答案含义和投影合同混用；集中合同可以在保留历史资料、默认不联网及既有权限的前提下逐段接入新版。

考虑过继续在各入口分散补判断，也考虑过整体迁移前端框架或拆分云服务。前者修改快但会重复漂移；后者增加构建、迁移和部署成本，不能直接解决本次合同断层。后续只有在实际界面或并发/运维需求证明有收益时，再分别评估这些迁移。

操作能力只说明兼容性，所有权、角色、会话、源修订、期限与撤销仍由应用服务核对。新模型、可保存归档、可分享摘要是三个独立交付步骤；默认关闭未实现操作。profile的题序、量表文字或选项/游戏含义改变必须使用新profile，不能覆盖旧语义合同。
