# 本地后续成绩配对与描述复核（v1.9.0）

当前测评范围：本页报告操作沿用旧版14道规划/24道数字量表合同；新版游戏/30题特质尚未适配，明确拒绝进入旧云端或投影，不截断或混用分母。新旧档案与续答操作见 [测评版本说明](assessment-profiles.md)。

这是校准准备的数据检查工具。用户主动导入单科校内百分制JSON、选取本机报告、手动配对并填写实际测评日期，才生成预览；确认后只导出必要聚合。**没有联网、统计持久化、A-Level等级换算、阈值调整或真实样本校准。** 开发与演示仅使用虚构资料。

## 操作

1. 从「本机报告库」打开后续成绩配对。默认没有导入、报告选择或自动配对。可主动下载一行模拟格式模板；它只是格式样例，不包含本机资料，也不代表可分析的真实样本。
2. 选择本地JSON文件。一次只导入一个科目、同一考试日期、校内0–100百分制的1–100条结果；来源须声明为模拟或真实来源待核验。文件最多300000字节，JSON文字最多100000个UTF-16码元。合法格式示例：

```json
{
  "format": "bic-followup-results",
  "version": 1,
  "subject": "maths",
  "scale": "school_percent_0_100",
  "examDate": "2026-10-25",
  "bankVersion": "2026.10",
  "source": "synthetic",
  "outcomes": [
    {"studyId": "SAMPLE-001", "score": 0},
    {"studyId": "SAMPLE-002", "score": null}
  ]
}
```

3. 科目只可为`english/maths/physics/chemistry`；题库版本必须与当前版本相同。考试日期必须为真实ISO日历日期且不晚于浏览器本地今天，不能把预计考试结果提前当后续数据。`source`只能`synthetic`或`unverified_real`；后一项只作声明，系统不认证资料或使用授权。
4. `studyId`为唯一、区分大小写的1–40个ASCII字母/数字及下划线/连字符，首字符为字母或数字。即使这个字段实际是学号，也只留本机配对，不能因采用编号就称匿名。`score`只接受0–100有限数字或null；数字字符串/布尔/未知字段/重复编号整批拒绝，不能静默丢行。0是实际0分，null是成绩缺失。
5. 明确勾选10–100份当前题库、目标科完整的本机归档。无需完成整份规划或人格，也无需当前院校目录。每条结果手动选择一份已勾选报告并填写其**实际基线测评日期**；每报告/研究编号最多配对一次。没有按姓名、编号或相似度自动匹配。
6. 基线日期必须早于后续考试日期。报告上的日期只是展示文字，归档创建/编辑时间也不是实际考试时间，因此工具不自动解析或填入；日期由操作者核对，顺序校验不能证明真实时间。
7. 核对研究编号对应、每位学生至多一份和日期后勾选确认，生成预览。未配对结果/报告允许作为缺失诊断，但已配对缺日期、重复或矛盾配对会停止整批分析。取消一个报告只清与之有关的绑定，保留其他有效绑定；换文件清选择与绑定。
8. 核对预览与完整JSON，再确认下载去标识汇总。它不是原始备份，不能恢复编号、逐条成绩或配对。取消不下载。关闭/离开库/库刷新会清导入、私有姓名/编号/成绩、绑定和预览，不写入浏览器存储；若需再次分析需重新导入与核对。

## 缺失与均值口径

两条分解同时成立：

- 所选报告数 = 有成绩配对 + 空成绩配对 + 未配对报告。
- 导入结果行数 = 有成绩配对 + 空成绩配对 + 未配对结果。

只对「有成绩配对」计算两份独立的粗均值。基线从现有评分引擎重算完整目标科目的正确题数/总题数；后续取导入的数字成绩，均舍入至5个百分点。null、未配对、未选中的本机报告都不进入均值；没有可用成绩配对时均值为空，不显示0%能力。

两次考试即便都显示百分数，也不意味着试卷难度和量尺相同。因此不计算均值差、学习进步、预测误差、相关或新等级阈值，不称校准改善或预测有效。成绩代表的课程、考试条件和真实性仍需学校独立复核。

## 隐私和导出

所选报告数、导入行数、有成绩配对、空成绩配对、两种未配对数中，任一正数小于10，则**整个聚合压制**：所有数量、均值、分母与配对率都不展示/导出。0允许；这避免只隐藏一个罕见缺失项却留下可反推的补集。10是内部产品门槛，不是充分匿名、统计可靠或法律标准。

输出固定为`bic-followup-review`版本1，只有题库/科目/固定量表/来源、隐私及方法声明、未校准状态；允许显示时才有六类计数与两份粗均值。没有姓名、研究/报告/归档编号、逐条分数、精确日期、自由文案、人格或顾问审计。均值、已有背景和反复子集仍可能产生识别风险，仅限校内复核，不可据此任意公开。

生成前、导出前和确认框后都复查所选归档完整快照及文件/配对/日期/核对状态。变化、删除、损坏或读取失败会清预览并停止，不静默换成新结果。换文件或离开后的迟到文件读取也不能恢复私密内容。

输出固定`calibration.status: not_calibrated`、`thresholdsChanged: false`、`realSampleValidation: false`。真实样本来源、适用授权、学生独立性、时间范围和学科教师审校尚待公司；模拟资料只能验证工具行为。正式阈值拟合、外部验证、常模与规则/AI的A/B事件仍未实施。原 [学术v1](academic-statistics.md) / [专业地区v2](planning-statistics.md) 格式与账号API/schema保持，不自动把本批成绩混入其他汇总。

开发测试包括严格导入、真实日历/本地日界、0与null、两条分解、重复/未知绑定/时间顺序、完整科目与题库、整份压制、输入不变、异步迟到/快照变化/取消导出/375px与file://。准确验证数和后续见 [持续台账](progress.md)。
