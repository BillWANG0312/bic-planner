# 顾问跨报告完成度清单（v1.12.0，格式v1）

这是带姓名和报告编号的**私密校内清单**，可用于检查获准报告的测评完成情况。不是匿名统计、成绩单、能力比较、录取预测或真实样本校准。本文格式v1仅汇总完成度；现可明确勾选 [学科表现v2](teacher-academic.md) 独立扩展29列，默认v1仍保持。现另有独立选择的 [学生自选偏好v3](teacher-preferences.md)，原v1/v2格式保持。

## 授权与操作

打开学校同源HTTPS下的`teacher-summary.html`。主动连接、登录学校顾问账号，再点击刷新；打开页面、连接或登录不自动列学生或读取答卷。只有原所有者明确授予当前顾问的有效`full_report_read_only`授权可选；advisor角色本身、家长链接/批注和建议编辑授权不授此入口权限。现有完整只读授权本来允许读取/复制同份资料，本入口只提取其必要子集；新授权预览和确认明确提示可保存含姓名/编号的校内完成度CSV。

1. 逐份勾选1–20个有效只读授权，无默认全选。只读取所选报告，不后台抓取全校或所有可读答卷。
2. 点击「核对所选报告并预览」，服务端在同一数据库读取快照中核对这批权限、修订与记录，只向页面返回必要摘要。任一报告失效/损坏/版本不符整批拒绝，不下载剩余行。
3. 核对姓名、编号、版本及计数。21列较宽，手机可在表格内部左右滚动，页面不会横向溢出。
4. 点击导出，先重新读取同批快照并比对，确认含身份资料的校内用途提示，再读取并比对一次；仅全部一致才下载固定文件名`bic-teacher-completion-v1.csv`。取消不下载，不产生替代文件。

选择、刷新、身份、授权期限/撤销或源修订变化会使旧预览失效；读取失败不自动重试或重新计算后导出。所选授权最早到期会清预览与选择，即使尚未点击预览；断开、注销、换账号或离开会清名单及CSV。迟到响应不能恢复旧资料，多标签Cookie变更由页面CSRF绑定拒绝。没有后台轮询，请主动刷新；最后核对之后已经下载、复制或截图的内容无法收回。

同一个原报告不能重复选择。报告编号在服务端仅按所有者唯一；不同所有者的同编号若出现在同批，整批拒绝以免清单混淆，请明确分批导出，不按同名自动去重或推断同一学生。

## 字段与口径

CSV固定21列：姓名、报告编号、年级、服务端修订、题库版本、目录版本、完成状态，四科学术已答/总题（8列），规划已答/总题/必答已答/必答总题（4列），性格已答/总题（2列）。显示年级按报告引擎基本信息优先、规划有效年级回退。目录缺省或`unknown`显示「未记录」，旧目录原值保留；完成度不使用院校规则，不据此重算专业建议。

学术每科15题，合法选项0、数值0均计已答，null缺答不计；不返回答案、正误或分数。规划总14题，其中`weakSubjects`为可选题，明确回答空数组算已答，缺省不计已答但不阻止必答完成；13道必答另列，基本信息中的有效年级与原报告一样补入规划题。性格总24题，合法0–4均计已答，null不计，不输出人格类型。

只有60学术题、13道规划必答和24道人格题均已答时，状态为「必答已完成」，否则「必答未完成」。这仅为作答覆盖，不表示答对、能力达标或教师审核完成。服务端计数与当前版本实际浏览器报告引擎有对照回归。

题库必须为当前`2026.10`，未知或旧题库整批拒绝；不能静默按新题库重算旧答卷。格式v1固定，不将以后新增成绩或规划字段悄悄混入本清单。

CSV带UTF-8 BOM、CRLF、字段引号及双引号转义；公式或控制字符前缀会增加单引号作为文本保护，表格预览仍显示原文。没有归档/授权/数据库ID、账号、精确日期、原始答卷、自由建议、便携actor/完整审计、家长讨论、凭据、人格类型或专业/地区推断。姓名及业务报告编号仍可识别学生，不能对外公开或称充分匿名。

## API与数据边界

`POST /api/teacher-summaries`，体仅`{grant_ids:[1–20个唯一安全ID]}`。虽用POST传明确选择，本接口只读，没有新增数据或授权。使用登录Cookie、精确Origin、写请求CSRF和页面身份绑定；浏览器不会把旧Cookie账号资料放到原账号名下。

返回固定`{format:"bic-teacher-completion-summary",version:1,items:[{grant,report}]}`。grant沿用只读12键元数据，report固定姓名/编号/年级/版本/修订/状态及完成度计数。服务端内部读取并严格校验获准记录，页面不接收原始答案/建议/历史，也不调用完整报告读取接口。

一条JOIN语句同时读取所选报告、授权和双方账号；核对接收顾问角色/双方启用、归属、源修订、撤销与期限后才返回整个批次。无权或失效404；重复授权/原报告/编号、额外字段或格式422；旧/未知题库409 VERSION；损坏503不回显私文。响应no-store/no-referrer/noindex。名单和摘要只留页面内存，不访问浏览器存储、本机报告库、统计工具或外部服务，不自动上传。

数据库仍为schema5，健康API仍2，没有新表、迁移或后端导出缓存。既有精确v1/v2/v3/v4→5升级及停服务私有备份/回退要求仍适用，见 [顾问编辑说明](advisor-edit.md#schema5升级与回退)。前后端一起更新；旧服务没有此接口。直接file://打开只能查看未连接入口，不能访问账号服务。

## 验证与限制

只用虚构账号/报告验证单批快照、权限/版本/损坏整批拒绝、0/null/可选题、原引擎计数对照、CSV公式转义、选择/确认前后新鲜度、到期/撤权/换账号/迟到清理、取消下载、无存储和375px。准确数量和证据见 [进度台账](progress.md)。没有公司正式部署、真实学生资料读取、模型请求、真实校准或消息发送。
