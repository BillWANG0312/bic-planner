# 账号与服务端报告存储阶段

本阶段交付可隔离运行、可测试的自托管 API，不连接公司生产环境、不改变静态网页的默认本机模式，也不自动上传任何已有学生资料。当前仓库没有 NAS 的 server.py、服务器权限、HTTPS 反代或正式账号配置；部署是明确的后续依赖。

## 实现范围

- FastAPI + SQLite，成熟的 pwdlib/Argon2 密码哈希；账号由有服务器权限的操作员通过交互命令创建，没有公开注册或默认口令。
- student/advisor 角色先均只能访问自己拥有的记录；不因 advisor 名称就获得所有学生资料。教师分配、跨用户授权在后续接口阶段单独实现。
- 使用服务端保存的会话：随机令牌只通过 HttpOnly Cookie 交付，数据库存令牌摘要；会话过期、注销和禁用用户均撤销访问。
- HTTPS 为正式模式要求；仅明确启用的回环地址开发模式可关闭 Secure Cookie。写操作必须匹配配置的 Origin，已登录写操作另需 CSRF 请求头。默认不开跨域与匿名写接口。
- 接收与本机归档一致的最小作答/顾问记录，严格校验。名单接口不返回全答卷；单份详情、创建、修改、删除均按当前账号筛选。修订号防止多设备覆盖，重复编号和配额冲突拒绝而不是静默替换。
- 数据库必须位于静态站点目录之外，避免被原静态服务器下载。账号及会话数据不打包进源码或交付包。

## 验证和后续

先在独立临时数据库测试身份、会话、CSRF/Origin、跨账号隔离、数据校验、配额、修订冲突、重启持久化与错误信息不泄露口令。静态原有测试继续通过。使用实际 HTTP 回环冒烟验证运行入口。

不在本段同时铺开前端账号界面、家长分享或 AI。核心稳定后，再做显式选择的前端云端连接、受控授权、只读分享的期限与撤销以及批注权限。未经部署验证不得称为“云端已上线”。
